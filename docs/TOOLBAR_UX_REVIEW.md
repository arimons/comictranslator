# 영역 분석 도구 모음 검토와 변경

2026-10-20. 삭제는 화면에 즉시 반영하고, 무거운 재분석은 Cmd/Ctrl+Enter로 모아 실행한다.

## 반영한 변경

- R 제거의 X 단축키와 상시 도구 버튼을 없앴다. 우클릭 메뉴의 **이 처리 영역 제외**로 옮겼다. TG와 R이 겹치면 메뉴에서 TG 제외/R 제외를 직접 고른다. 수동 영역은 가이드 삭제로 처리한다.
- 우클릭 자체는 삭제하지 않는다. 메뉴는 화면 밖으로 잘리지 않으며 Escape·바깥 클릭으로 닫고 방향키로 항목을 고를 수 있다.
- TG를 제외하면 그 상자를 즉시 숨긴다. 모든 연결 TG가 제외된 자동 R도 숨긴다. 일부 TG가 남으면 R 경계는 다음 분석까지 유지한다. R을 제외하면 연결 TG 표시도 숨긴다.
- 삭제한 미적용 편집을 Cmd/Ctrl+Z로 되돌리면 캔버스를 즉시 복원한다. 이 과정은 API·LaMa·Telea를 실행하지 않는다.
- 미적용 변경이 있음을 표시한다. 실제 마스킹·OCR sheet 재생성은 버튼 클릭 또는 Cmd/Ctrl+Enter에서만 실행한다. 일반 Enter는 적용 버튼에 포커스돼 있어도 실행하지 않는다. 현재 페이지에 적용하며 프로젝트 전체 재분석이 아니다.
- 기존 적용 시 Undo 초안 기록을 정리하는 정책은 유지한다. 적용 후 결과 이미지 자체를 버전별로 되돌리는 기능은 이번 범위가 아니다.
- 9개 도구를 8개로 줄이고 역할별 구분선을 넣었다. 문자·이모지 아이콘 대신 같은 굵기의 SVG 선 아이콘을 사용하고 한국어 도구명·단축키를 tooltip에 표시한다.

기존 JSON·제외 기록·캐시 형식은 바꾸지 않는다. UI의 미리보기만 현재 편집 지시를 반영하며, 저장된 분석을 바꾼 것처럼 표시하지 않는다.

## 사용성 판단

주요 문제는 같은 ‘제외’가 TG·R·페이지에 중복된 도구로 보이고, T×·T/·╱·□·●만으로 조작 결과를 알기 어려웠다는 점이다. 페이지 제외는 상단 상태 버튼, TG 제외는 반복 클릭 도구/선택 후 Delete, R 제외는 해당 영역의 우클릭 명령으로 나누는 구성이 적합하다.

| 역할 | 현재 키 | 아이콘 표현 | 판단 |
|---|---|---|---|
| 선택 | V | 화살표 커서 | 유지 |
| 이동 | H / Space 누른 채 드래그 | 손 | 유지. 잠깐 이동은 Space 우선 |
| TG 제외 | D / 선택 후 Delete | 글자 상자와 빼기 | D는 여러 TG를 연속 제외할 때 유용 |
| TG 분할 | T | 글자 상자 내부의 분할선 | R 분할과 이름을 함께 표시 |
| Edge 장벽 | E | 벽과 경계에 막힌 화살표 | 글자 입히기의 E 지우개와 다르므로 탭별 이름·아이콘이 중요 |
| 영역 분할 | L | 영역 외곽과 대각 분할선 | L은 기억하기 어려우나 기존 사용자를 위해 유지 |
| 텍스트 기반 영역 | U | 모서리 상자와 T | 과거 Unboxed의 U를 호환 키로 유지 |
| 경계 기반 시작점 | B | 말풍선 외곽과 점 | 점만 있던 아이콘보다 시작점의 목적이 분명 |

Cmd/Ctrl+Z, Shift+Cmd/Ctrl+Z, Cmd/Ctrl+Enter와 기존 보기 키는 유지한다. 일반 Enter에 무거운 실행을 다시 연결하지 않는다. R 제외에 새로운 전역 단축키도 추가하지 않는다.

추가 제안은 **T / Shift+T를 TG 분할 / 영역 분할로 짝짓는 것**이다. 아직 반영하지 않았다. 현재 L에 익숙한 동작을 바꾸기보다, 실제 사용 후 Shift+T 별칭을 추가할지 정하는 편이 낫다. 도구 폭을 더 넓혀도 괜찮다면 선택한 도구 옆에 짧은 이름을 항상 표시하는 방식도 다음 후보지만 현재는 tooltip과 캔버스 제목으로 유지한다.

## 검증과 구현

- `frontend/src/EditorCanvas.jsx`: 우클릭 메뉴, 즉시 숨김, 선택 동작.
- `frontend/src/regionExclusion.js`: TG 제외·R 제외의 미리보기 조건.
- `frontend/src/GuidanceToolIcon.jsx`: 공통 SVG 도구 아이콘.
- `frontend/src/App.jsx`, `frontend/src/keymap.js`: 미적용 표시, 명시적 적용, 일반 Enter 차단, 단축키 도움말.
- `proof/src/test_region_exclusion.mjs`: 부분 TG 제외·전체 TG 제외·복원·수동 영역 보존.
- `proof/src/check_deferred_analysis.js`: TG/R 삭제와 Undo의 캔버스 픽셀 복원, 우클릭만으로 삭제하지 않음, 일반 Enter 차단, Cmd+Enter 요청 1회, 도구 8개를 브라우저 응답 fixture로 확인한다. 분석 POST는 실제 서버로 보내지 않는다.
- 이전 `proof/src/check_region_off_click.js`도 새 우클릭 메뉴로 갱신했다.

실제 LaMa 성능 시간은 측정하지 않았다. 현재 코드가 제외 변경 시 기존 unboxed 마스크를 재사용하지 않으므로, 매 클릭마다 전체 적용을 호출하지 않는 구조로 정리한 것이다.

검증 결과: 전체 pytest 520개·하위 검사 13개 통과. 브라우저 검증에서는 자동 분석 요청 없이 미리보기와 Undo를 확인하고, 명시적 Cmd+Enter에만 fixture 적용 요청이 1회 발생했다. 메뉴/새 아이콘 캡처는 `proof/misc/toolbar-contextmenu.png`에 보관한다.
