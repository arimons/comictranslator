# 편집기 할 일

갱신: 2026-10-20.UI/UX 개선을 먼저 진행하고, MCP 후속 기능은 아래 목록에서 이어간다.

## 작품별 번역 용어집

구현과 사용법: [작품별 번역 용어집](WORK_GLOSSARY.md).

- [x] 작품을 한 번 확인받은 뒤 이미지 수동 편집과 병행해 웹 조사한다.
- [x] 검색 인용 근거가 있는 대응은 자동 적용하고 충돌·불확실 항목만 검토 목록에 둔다.
- [x] 작품별 용어집 재사용, 수동 확정·제외 보존, 번역에 실제 사용한 버전을 기록한다.
- [ ] 사용자가 확인한 실제 작품으로 조사 정확도와 동일 페이지의 번역 전후 품질을 비교한다.

## MCP 검토 후속 작업

현재 구현과 사용법: [편집기 검토 MCP](editor_mcp.md). 조회와 미적용 검토 초안 저장까지 구현됐다.

- [ ] 실제 작품에서 원본·분석·마스킹·결과 비교로 1차 관찰 흐름을 점검한다. 시각적 분류와 품질 기준은 사용자가 확인한다.
- [ ] 초안의 관찰·수정 후보·근거 이미지를 편집기에서 확인할 수 있게 한다.
- [ ] 후보 동작을 별도 작업 폴더에서 실행해 원본과 비교할 수 있는 미리보기를 만든다.
- [ ] 사용자가 승인한 후보만 적용하는 기능을 만든다. 적용 직전에 페이지 revision을 다시 검사하고 취소·복원 경로를 제공한다.
- [ ] 재분석·OCR·번역 등 비용이 드는 실행 도구는 대상·비용 안내·명시적 실행 흐름을 설계한 뒤 공개한다.
- [ ] UI 개편 후에도 ID·원본 좌표·revision·기존 JSON/캐시 호환 계약이 유지되는지 확인한다.

## 홈 화면과 진행 상태

- [x] 원본 프로젝트를 유지하는 중앙 표지/우→좌 본문 페이지 미리보기. [사용법](PAGE_PREPARATION.md).
- [x] 작업 중 팝업을 없애고 서버 연결 상태등 제공.
- [x] 작은 비교 이미지 확대·너비 맞춤 및 창 크기 변경 시 캔버스 맞춤 재계산.

- [x] 시작 화면을 한국어로 정리하고 화면 너비에 맞춰 배치한다.
- [x] 불러오기 영역을 줄이고, 아래에 최근 프로젝트 썸네일 카드를 배치한다.
- [x] 기존 분석결과 활용 / 처음부터 다시 분석을 실제 실행 옵션에 연결한다.
- [x] 작품명·최근 작업 시각·분석 수·결과 생성 수를 표시한다.
- [ ] 페이지별 ‘수동 검토 완료’ 체크를 별도 저장한다. 결과 생성 수와 구별하며, 편집·재분석 후 완료 상태를 언제 해제할지 정한다.
- [ ] 수동 검토 완료가 구현되면 홈 카드에 `수동 검토 50 / 170장`을 추가한다.
