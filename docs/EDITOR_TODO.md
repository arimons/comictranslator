## 작품별 번역 용어집

구현과 사용법: [작품별 번역 용어집](WORK_GLOSSARY.md).

- [x] 프로젝트명 옆 작품 상태 표시, CV 기반 확인 작품 연결, 후보 확인·검색어 수정 후 재검색을 연결한다. 검색 실패 시 현재 연결을 보존한다.

- [x] 작품을 한 번 확인받은 뒤 이미지 수동 편집과 병행해 웹 조사한다.
- [x] 검색 인용 근거가 있는 대응은 자동 적용하고 충돌·불확실 항목만 검토 목록에 둔다.
- [x] 작품별 용어집 재사용, 수동 확정·제외 보존, 번역에 실제 사용한 버전을 기록한다.
- [ ] 사용자가 확인한 실제 작품으로 조사 정확도와 동일 페이지의 번역 전후 품질을 비교한다.

## MCP 검토 후속 작업

- [ ] 컬러 비율·배경 복잡도·글자와 그림의 겹침을 근거로 일반 렌더/이미지 재생성의 후보 경로를 제안한다. 기준은 실제 샘플을 사용자와 확인하고 컬러라는 이유만으로 재생성을 강제하지 않는다.
- [ ] **선택한 실행 경로: Codex 내장 이미지 생성 → 만화 앱에 결과 등록.** 현재 대화에서 내장 생성 도구에 특정 모델명을 지정할 수는 없으므로 gpt-image-2/Nano Banana Pro를 사용했다고 임의로 기록하지 않는다. 직접 API 호출은 이 경로의 자동 대체 수단으로 사용하지 않는다.
- [x] 내장 이미지 생성 결과를 페이지 ID·입력 revision·번역문/용어집 버전과 함께 미검토 후보로 등록하고 편집기에서 원본과 비교한다. 커버 1장으로 실제 stdio MCP 왕복을 확인했다. [구현 기록](IMAGE_GENERATION_REVIEW.md).
- [ ] 사용자가 확인한 생성 후보를 최종 output으로 채택·복원한다. 원본·기존 출력은 보존하며 시각 검토 전 자동 확정하지 않는다.
- [x] Codex 내장 도구용 생성 요청 묶음(원본·현재 용어집·번역·추가 지시)과 결과 등록 계약을 구현했다. 다른 웹 세션 연결은 미검증이다.
- [ ] 웹 세션과 Codex가 함께 사용할 생성 요청 묶음(원본 이미지, 확정 용어집, 추가 번역 지시, 있으면 확정 한국어 문장, 그림 보존 지시)을 내보낸다. 결과 수신 계약은 동일하게 쓰고, 프롬프트에 적힌 모델명을 실제 사용 모델의 증거로 취급하지 않는다. 현재 용어집 자동 주입은 일반 OCR/번역 경로에만 연결돼 있다.

현재 구현과 사용법: [편집기 검토 MCP](editor_mcp.md). 조회·미적용 검토 초안과 [이미지 생성 후보 등록](IMAGE_GENERATION_REVIEW.md)을 구현했다. 권장 표시만으로 자동 생성하지 않는다.

- [ ] 실제 작품에서 원본·분석·마스킹·결과 비교로 1차 관찰 흐름을 점검한다. 시각적 분류와 품질 기준은 사용자가 확인한다.
- [ ] 초안의 관찰·수정 후보·근거 이미지를 편집기에서 확인할 수 있게 한다.
- [ ] 후보 동작을 별도 작업 폴더에서 실행해 원본과 비교할 수 있는 미리보기를 만든다.
- [ ] 사용자가 승인한 후보만 적용하는 기능을 만든다. 적용 직전에 페이지 revision을 다시 검사하고 취소·복원 경로를 제공한다.
- [ ] 재분석·OCR·번역 등 비용이 드는 실행 도구는 대상·비용 안내·명시적 실행 흐름을 설계한 뒤 공개한다.
- [ ] UI 개편 후에도 ID·원본 좌표·revision·기존 JSON/캐시 호환 계약이 유지되는지 확인한다.
