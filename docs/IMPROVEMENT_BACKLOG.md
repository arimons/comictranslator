## 1. 메모리 점유

일괄 처리 중 한 프로세스가 8GB 넘게 쓰던 문제입니다. 원인 조사와 1차 조치는 11-01에 끝났고, 남은 것은 조치가 실제로 듣는지 맥에서 확인하는 일입니다. 경과는 [배치 메모리 증가 조사 메모](BATCH_MEMORY_GROWTH_NOTES.md)에 있습니다.

- [ ] **LaMa 작업 프로세스 종료 뒤 서버 점유가 실제로 내려가는지 맥미니에서 확인합니다.** 11-01에 서버의 LaMa를 별도 작업 프로세스로 옮겼지만, 그 측정은 클라우드(Linux·CPU)에서만 했습니다. 문제가 나던 환경은 맥의 MPS라서 `footprint <pid>`로 다시 재야 조치가 끝난 것인지 알 수 있습니다.
- [ ] **일괄 처리 스크립트의 40장 단위 재시작이 아직 필요한지 확인합니다.** `scripts/series_batch.py --max-pages 40`은 누수를 피하려던 회피책입니다. 위 확인에서 점유가 안정적이면 한 권을 한 번에 돌려 보고, 괜찮으면 회피책을 걷어냅니다.
- [ ] **끝난 복원 작업 기록을 지웁니다.** `app.py`의 `_RESTORE_JOBS`는 작업이 끝나도 항목을 지우지 않아, 며칠씩 켜 두는 서버에서 계속 쌓입니다. 크기는 작지만 지우는 코드가 아예 없습니다.
