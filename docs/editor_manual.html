Comic Translator editing workflow

MangaScript Pro 편집기 매뉴얼

이 문서는 만화 번역 파이프라인의 수동 보정 화면을 위한 사용자 가이드입니다. Guidance 단계에서는 말풍선과 영역 인식을 보정하고, Overlay 단계에서는 최종 텍스트 배치와 폰트, 지우개 보정을 다룹니다.

기본 흐름

Guidance

OCR과 floodfill이 헷갈리는 부분에 힌트를 줍니다. 텍스트 그룹 분리, edge wall, bubble, unboxed 영역을 직접 지정합니다.

OCR / Translation

Guidance를 반영해 OCR sheet와 번역 결과를 갱신합니다. 이 단계는 자동 파이프라인의 결과를 확인하는 중간 점검 구간입니다. OCR/번역 모델은 교체할 수 있으며, 선택지는 GET /api/ocr-models로 조회하고 실행 시 ocr_model로 지정합니다. 기본값은 gemini-3-flash-preview입니다.

Overlay

최종 렌더 결과 위에서 텍스트 박스, 폰트, 쓰기 방향, 줄바꿈, 수동 지우개를 조정합니다.

탭 이동은 Ctrl + 1, Ctrl + 2, Ctrl + 3으로 가능합니다. 각 탭의 단축키는 현재 탭에서만 동작합니다.

Guidance Editor

Guidance Editor는 원본 분석이 잘못된 지점을 알려주는 화면입니다. 여기서 만든 가이드는 floodfill, split, masking, OCR sheet 생성에 영향을 줍니다.

Text Group Off

번역 대상이 아니거나 잘못 묶인 텍스트 그룹을 끕니다. 잘못 끈 항목은 undo로 되돌릴 수 있습니다.

Guidance only D 또는 Delete

Text Group Split

하나의 텍스트 그룹이 여러 대사로 붙었을 때 분리 기준선을 긋습니다.

Guidance only T

Edge Wall

수동 edge는 사용자가 지정하는 가상의 벽입니다. 지정한 box가 상하좌우 경계가 되며, 인접 edge와 직접 overlap이 없으면 서로 독립적으로 취급되어야 합니다.

Guidance only E

Bubble / Ubox

말풍선 영역은 Bubble로, 말풍선 밖 일반 대사는 Ubox로 지정합니다. 작은 클릭은 seed point, 드래그는 box guide가 됩니다.

Guidance only S, U

Guidance 시각화 색상

표시의미사용 기준
파란 rect 자동 인식된 region 또는 선택된 분석 대상입니다. 결과가 맞으면 그대로 둡니다.
빨간 edge 사용자가 직접 지정한 가상의 경계입니다. 말풍선 경계가 열려 있거나 flood가 새는 경우 사용합니다.
주황 split 분리 기준선입니다. 같은 bubble 안에서 대사가 두 개 이상으로 갈라질 때 사용합니다.

Overlay Result Editor

Overlay 단계는 최종 결과를 보며 실제 텍스트 배치를 수정하는 화면입니다. 왼쪽에는 원본 이미지가 유지되고, 오른쪽에서 overlay 결과와 safe rect를 조정합니다.

safe rect 편집

동작결과메모
박스 첫 클릭 region을 선택합니다. 첫 클릭만으로 resize가 시작되지 않습니다.
선택된 박스 내부 드래그 safe rect 위치를 이동합니다. 마우스로 대략 이동한 뒤 방향키로 미세 조정합니다.
선택된 박스 edge 드래그 한쪽 방향으로 크기를 조절합니다. 좌우상하 border가 resize 핸들처럼 동작합니다.
선택된 박스 corner 드래그 대각선 방향으로 크기를 조절합니다. 드래그 중 빨간 preview rect가 즉시 따라옵니다.
빈 영역 클릭 선택과 highlight를 해제합니다. 렌더 결과 확인을 방해하는 빨간 테두리를 숨길 때 사용합니다.

텍스트와 폰트

Floating Text Editor

safe rect를 더블클릭하면 대사 편집 팝업이 열립니다. 여러 줄 대사를 직접 입력하고 Ctrl + Enter 또는 Apply로 반영합니다.

Font Style

Normal, Bold, Impact, Serif, Serif Emphasis, Handwritten, Etc를 선택할 수 있습니다. Etc는 직접 폰트 파일을 지정하는 용도입니다.

Writing Mode

가로쓰기와 세로쓰기는 동시에 켜지지 않는 선택값입니다. 자동 추정이 틀렸다면 H 또는 V로 강제 지정합니다.

Font Size Offset

+와 -는 3 step 단위로 조정합니다. 작은 버튼은 1 step 단위의 세밀한 조정에 사용합니다.

수동 지우개

D를 누르고 있는 동안 지우개 모드가 켜집니다. 그 상태로 드래그하면 흰색 eraser rect가 생성되고, 다음 overlay render에서 텍스트를 다시 얹기 전에 해당 영역을 흰색으로 채웁니다.

지우개는 최종 레이아웃 보정용입니다. 안 지워진 원문 흔적이나 작은 잔상을 정리하는 데 쓰고, 큰 마스킹 실패는 Guidance 단계에서 region이나 edge를 다시 잡는 편이 좋습니다.

작업 팁

Edge가 기대와 다르게 새는 경우

Edge는 실제 벽처럼 작동해야 합니다. 그래도 rescue가 실패하면 팝업의 실패 이유와 rect 정보를 보고 edge box가 너무 작거나 TG와 overlap이 없는지 확인합니다.

split bubble의 인접 region 영향

수동 폰트, safe rect, 세로쓰기, 텍스트 override가 들어간 region은 자동 split sibling 보정에서 격리됩니다. 한 region 수정이 이웃 font를 바꾸면 버그로 보면 됩니다.

줄바꿈이 중요한 대사

Floating editor에서 직접 줄바꿈을 넣으면 renderer가 그 줄바꿈을 우선 보존합니다. 너무 좁은 rect에서는 font size를 조금 낮추거나 safe rect 폭을 늘립니다.

최종 확인 순서

원본 이미지에서 폰트 분위기를 보고, 오른쪽 overlay 결과에서 safe rect와 줄바꿈을 조정한 뒤, 지우개로 잔상만 마지막에 정리합니다.

제품명 아이디어

현재 이름인 MangaScript Pro는 기능을 꽤 잘 설명합니다. 다만 “Pro”가 붙으면 범용 상용 툴 느낌이 강하고, 프로젝트의 개성인 말풍선 편집과 번역 조판 감각은 조금 덜 드러납니다.

MangaScript Pro 안정적인 상용 툴 느낌입니다. 그대로 써도 무난합니다.

BubbleScript 말풍선 중심 편집기를 가장 직관적으로 드러냅니다.

PanelScribe 만화 컷과 대사 조판을 함께 다루는 느낌이 좋습니다.

LetterBubble 귀엽고 실무적인 이름입니다. 번역문을 말풍선에 넣는 용도가 바로 보입니다.

ComiTypeset 번역보다 조판 품질을 강조합니다.

FrameLetter 컷 단위 편집과 텍스트 배치를 차분하게 표현합니다.

BubbleForge 수동 보정과 제작 도구 느낌이 강합니다.

ScriptLayer overlay와 대사 레이어 개념에 잘 맞습니다.

MangaLetter Lab 연구와 제작을 겸하는 내부 툴 감성이 있습니다.

Comic Translator Studio 프로젝트명과 제품 성격을 가장 명확하게 연결합니다.

개인적으로는 외부 공개용이면 PanelScribe나 BubbleScript가 좋고, 현재 프로젝트 정체성을 유지하려면 Comic Translator Studio가 가장 덜 흔들립니다. MangaScript Pro는 상단 브랜드명으로 두고, 문서나 저장소 설명에는 Comic Translator를 병기하는 방식도 괜찮습니다.

이 문서는 현재 UI 기준으로 작성되었습니다. 세부 단축키나 렌더 정책이 바뀌면 Overlay와 Guidance 섹션을 함께 갱신하세요.
