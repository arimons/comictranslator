Comic Translator editing workflow

MangaScript Pro 편집기 매뉴얼

이 문서는 만화 번역 파이프라인의 수동 보정 화면을 위한 사용자 가이드입니다. Guidance 단계에서는 말풍선과 영역 인식을 보정하고, Overlay 단계에서는 최종 텍스트 배치와 폰트, 지우개 보정을 다룹니다.

기본 흐름

작업은 Start page에서 이미지를 불러오는 것으로 시작합니다. Drop files here 영역에 이미지 파일을 끌어다 놓거나 Load Files 버튼으로 고르면 됩니다. 프로젝트에 같은 이름의 이미지가 이미 있으면 덮어쓰지 않고 앞에 번호를 붙인 새 이름으로 추가합니다. 같은 원본 파일을 여러 프로젝트가 함께 쓰기 때문에, 덮어쓰면 다른 프로젝트의 이미지까지 바뀔 수 있어서입니다.

여러 장을 한꺼번에 분석하다가 한 장이 실패해도 나머지는 끝까지 처리합니다. 실패한 이미지는 목록에 실패로 표시되고, 로그 끝에 "일부 이미지 분석 실패"가 남습니다.

Guidance

OCR과 floodfill이 헷갈리는 부분에 힌트를 줍니다. 텍스트 그룹 분리, edge wall, bubble, unboxed 영역을 직접 지정합니다.

OCR / Translation

Guidance를 반영해 OCR sheet와 번역 결과를 갱신합니다. 이 단계는 자동 파이프라인의 결과를 확인하는 중간 점검 구간입니다. OCR/번역 모델은 탭 안의 선택 상자에서 바꿀 수 있습니다. 자세한 내용은 아래 OCR / Translation 항목에 있습니다.

Overlay

최종 렌더 결과 위에서 텍스트 박스, 폰트, 쓰기 방향, 줄바꿈, 수동 지우개를 조정합니다.

탭 이동은 Alt + 1부터 Alt + 5까지입니다. 순서는 말풍선 분석, 글자인식/번역, 글자 입히기, 내보내기, 배경 복원입니다. macOS에서는 이 문서의 Ctrl 자리에 Cmd를, Alt 자리에 Option을 누릅니다. 각 탭의 단축키는 현재 탭에서만 동작하고, ?로 지금 탭의 단축키를 볼 수 있습니다.

Guidance Editor

Guidance Editor는 원본 분석이 잘못된 지점을 알려주는 화면입니다. 여기서 만든 가이드는 floodfill, split, masking, OCR sheet 생성에 영향을 줍니다.

Text Group Off

번역 대상이 아니거나 잘못 묶인 텍스트 그룹을 끕니다. 잘못 끈 항목은 undo로 되돌릴 수 있습니다.

Guidance only D 도구. 선택한 TG는 Delete로 바로 끕니다.

Text Group Split

하나의 텍스트 그룹이 여러 대사로 붙었을 때 분리 기준선을 긋습니다.

Guidance only T

Edge Wall

수동 edge는 사용자가 지정하는 가상의 벽입니다. 지정한 box가 상하좌우 경계가 되며, 인접 edge와 직접 overlap이 없으면 서로 독립적으로 취급되어야 합니다.

Guidance only E

Bubble / Ubox

말풍선 영역은 Bubble로, 말풍선 밖 일반 대사는 Ubox로 지정합니다. 작은 클릭은 seed point, 드래그는 box guide가 됩니다.

Ubox는 사각형 전체를 지우지 않고, 사각형 안에서 글자 색과 같은 픽셀만 골라 지웁니다. 배경이 흰색처럼 평평하면 Telea, 망점·어두운 배경·선화면 LaMa가 자동으로 고릅니다. 박스 안에 속도선이나 머리카락 끝이 걸리면 그 선도 글자로 보고 함께 지우니, 박스는 글자와 후리가나에 바짝 붙여 잡습니다.

Action History의 Ubox 줄 오른쪽 LaMa 버튼을 켜면 배경 판정과 관계없이 LaMa로 지웁니다. 망점 위 글자가 매끈하게 번져 지워졌다면 켜 봅니다.

Guidance only B, U

OCR / Translation

이 탭에서는 Guidance를 반영한 OCR sheet로 글자 인식과 번역을 실행합니다. 실행하기 전에 어떤 모델을 쓸지, 번역에 어떤 힌트를 줄지 정해 둡니다.

OCR/Translation Model

글자 인식과 번역을 맡을 모델을 고릅니다. 목록은 서버가 지원하는 모델(GET /api/ocr-models)로 채워지고, 선택 상자에 마우스를 올리면 고른 모델의 메모가 보입니다. 메모에는 속도나 품질 특징이 짧게 적혀 있어 모델을 바꿀 때 참고할 수 있습니다. 기본값은 Gemini 3 Flash입니다.

Additional Translation Prompt

번역 톤, 고유명사, 말투, 문맥 힌트를 적어 두면 OCR/번역 요청에 함께 전달됩니다. "-반말로"처럼 -로 시작하는 문장도 그대로 전달됩니다.

고른 모델과 추가 번역 프롬프트는 프로젝트마다 따로, 지금 쓰는 브라우저(localStorage)에 기억됩니다. 같은 프로젝트를 다시 열면 그대로 돌아오지만, 다른 브라우저나 다른 컴퓨터에서는 보이지 않습니다. 서버가 아니라 브라우저에 저장하기 때문입니다. Start page의 Recent Projects에서 프로젝트를 Delete하면 기억해 둔 설정도 함께 지워집니다.

Overlay Result Editor

Overlay 단계는 최종 결과를 보며 실제 텍스트 배치를 수정하는 화면입니다. 왼쪽에는 원본 이미지가 유지되고, 오른쪽에서 overlay 결과와 safe rect를 조정합니다.

safe rect 편집

텍스트와 폰트

Floating Text Editor

safe rect를 더블클릭하거나, region을 고른 채 Enter를 누르면 대사 편집 팝업이 열립니다. 여러 줄 대사를 직접 입력한 뒤 Apply를 누르면 대사만 반영하고 팝업을 닫습니다. Ctrl + Enter는 대사를 반영하고 overlay render까지 바로 실행합니다. 다른 render가 진행 중이면 그것이 끝난 뒤 한 번 실행합니다. Esc는 고친 내용을 버리고 닫습니다.

Font Style

Normal, Bold, Impact, Light, Serif, Serif Bold, Handwritten, EFX, Etc를 선택할 수 있습니다. EFX는 내부 이름이 serif emphasis인 강조 서체입니다. Etc는 직접 폰트 파일을 지정하는 용도입니다.

Writing Mode

가로쓰기와 세로쓰기는 동시에 켜지지 않는 선택값입니다. 자동 추정이 틀렸다면 region을 선택한 상태에서 O를 누릅니다. 누를 때마다 자동 → 가로 → 세로 → 자동으로 바뀌고, 화면 아래에 바뀐 방향이 잠깐 표시됩니다.

Font Size Offset

=와 -는 3 step 단위로 조정하고, Shift를 함께 누르면 1 step 단위로 조정합니다. 일반 키보드에서 +는 Shift + =로 입력되므로 1 step으로 동작합니다. 숫자패드의 +는 3 step입니다. Selected Style의 작은 −/+ 버튼도 1 step 단위입니다.

자동 미리보기

Auto preview 300ms를 켜 두면 편집을 멈추고 0.3초가 지났을 때 overlay를 자동으로 다시 렌더링합니다. 다시 렌더링해도 확대·이동해 둔 화면은 그대로 유지되므로, 작은 글자를 크게 본 상태에서 계속 고칠 수 있습니다. 다른 페이지로 넘어가면 화면은 새 페이지에 맞춰 다시 맞춰집니다.

수동 지우개

E를 누르거나 캔버스 왼쪽 위 ⌫ 버튼을 누르면 지우개 도구가 켜지고, 한 번 더 누르면 꺼집니다. 지우개 도구로 드래그하면 흰색 eraser rect가 생성되고, 다음 overlay render에서 텍스트를 다시 얹기 전에 해당 영역을 흰색으로 채웁니다. 끌지 않고 이미 있는 eraser rect를 클릭하면 그 영역이 선택되고, Delete로 지울 수 있습니다.

지우개는 최종 레이아웃 보정용입니다. 안 지워진 원문 흔적이나 작은 잔상을 정리하는 데 쓰고, 큰 마스킹 실패는 Guidance 단계에서 region이나 edge를 다시 잡는 편이 좋습니다.

배경 복원

Ubox 사각형으로는 깔끔하게 지워지지 않는 곳을 직접 칠해서 LaMa로 다시 지우는 화면입니다. 흰 글자가 같은 흰 바탕과 맞닿아 있거나, 속도선이 글자를 가로지르는 경우처럼 사각형 안에서 글자와 배경을 색으로 나눌 수 없을 때 씁니다.

  1. 자동 마스크를 누르면 말풍선 밖 글자 위치로 지울 영역(빨강)을 만듭니다.
  2. 지우개(E)로 배경까지 잡힌 부분을 걷어 내고, 칠하기(B)로 빠진 글자 부분을 더합니다.
  3. 문맥 영역(C)으로 LaMa가 참고할 범위를 사각형으로 감쌉니다. 해당 컷 안으로만 잡고, 옆 컷이 섞이지 않게 합니다.
  4. 복원 실행 후 결과가 괜찮으면 이 결과 확정을 누릅니다. 확정한 패치는 글자 입히기 렌더 때 마스크 안쪽에만 합성됩니다.

처리 해상도는 기본값 "원본 크기"를 권합니다. 마스크 바깥 픽셀은 바뀌지 않도록 검사하며, 실패하면 기존 결과를 덮어쓰지 않습니다.

단축키

조작 방식은 Figma 같은 디자인 도구에 맞췄습니다. 휠은 화면을 옮기고, 핀치나 Ctrl + 휠이 확대합니다. macOS에서는 이 문서의 Ctrl 자리에 Cmd를, Alt 자리에 Option을 누릅니다. 편집 화면에서 ?를 누르면 지금 탭에서 쓸 수 있는 단축키만 모아 보여 줍니다. 이 표와 도움말은 같은 정의(frontend/src/keymap.js)에서 나옵니다.

입력칸에 글자를 쓰는 중이거나 한글을 조합하는 중에는 글자·숫자 단축키가 동작하지 않습니다. 글자 키는 자판 위치로 판정하므로 한글 입력 상태여도 같은 키로 동작합니다. 일반 Enter는 아무것도 적용하지 않습니다. 적용은 항상 Ctrl + Enter입니다.

글꼴, 쓰기 방향, 글자 크기, 방향키 이동은 region을 선택했을 때만 동작합니다. 숫자 스타일 키는 다른 키와 함께 누르면 무시합니다. Shift + 숫자는 보기 조작(맞춤·100%·선택 확대)입니다. Ctrl + Z는 이 페이지에서 한 편집(이동, 크기, 회전, 스타일, 글자 크기, 대사, 지우개)을 최대 100단계까지 되돌리고, 되돌린 결과로 auto preview가 다시 렌더링합니다. 페이지를 옮기면 기록은 비워집니다.

작업 팁

Edge가 기대와 다르게 새는 경우

Edge는 실제 벽처럼 작동해야 합니다. 그래도 rescue가 실패하면 팝업의 실패 이유와 rect 정보를 보고 edge box가 너무 작거나 TG와 overlap이 없는지 확인합니다.

split bubble의 인접 region 영향

수동 폰트, safe rect, 세로쓰기, 텍스트 override가 들어간 region은 자동 split sibling 보정에서 격리됩니다. 한 region 수정이 이웃 font를 바꾸면 버그로 보면 됩니다.

줄바꿈이 중요한 대사

Floating editor에서 직접 줄바꿈을 넣으면 renderer가 그 줄바꿈을 우선 보존합니다. 너무 좁은 rect에서는 font size를 조금 낮추거나 safe rect 폭을 늘립니다.

최종 확인 순서

원본 이미지에서 폰트 분위기를 보고, 오른쪽 overlay 결과에서 safe rect와 줄바꿈을 조정한 뒤, 지우개로 잔상만 마지막에 정리합니다.

제품명 아이디어

현재 이름인 MangaScript Pro는 기능을 꽤 잘 설명합니다. 다만 “Pro”가 붙으면 범용 상용 툴 느낌이 강하고, 프로젝트의 개성인 말풍선 편집과 번역 조판 감각은 조금 덜 드러납니다.

MangaScript Pro 안정적인 상용 툴 느낌입니다. 그대로 써도 무난합니다.

BubbleScript 말풍선 중심 편집기를 가장 직관적으로 드러냅니다.

PanelScribe 만화 컷과 대사 조판을 함께 다루는 느낌이 좋습니다.

LetterBubble 귀엽고 실무적인 이름입니다. 번역문을 말풍선에 넣는 용도가 바로 보입니다.

ComiTypeset 번역보다 조판 품질을 강조합니다.

FrameLetter 컷 단위 편집과 텍스트 배치를 차분하게 표현합니다.

BubbleForge 수동 보정과 제작 도구 느낌이 강합니다.

ScriptLayer overlay와 대사 레이어 개념에 잘 맞습니다.

MangaLetter Lab 연구와 제작을 겸하는 내부 툴 감성이 있습니다.

Comic Translator Studio 프로젝트명과 제품 성격을 가장 명확하게 연결합니다.

개인적으로는 외부 공개용이면 PanelScribe나 BubbleScript가 좋고, 현재 프로젝트 정체성을 유지하려면 Comic Translator Studio가 가장 덜 흔들립니다. MangaScript Pro는 상단 브랜드명으로 두고, 문서나 저장소 설명에는 Comic Translator를 병기하는 방식도 괜찮습니다.

이 문서는 현재 UI 기준으로 작성되었습니다. 세부 단축키나 렌더 정책이 바뀌면 Overlay와 Guidance 섹션을 함께 갱신하세요.
