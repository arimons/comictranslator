# 작업 데이터와 의존성 정리

2026-10-21. 프로젝트 ID는 기존 timestamp 폴더명을 유지한다. project.json의 project_name은 표시 이름이므로 바뀌어도 경로를 바꾸지 않는다.
코드 저장소와 작업 데이터 홈을 구분하는 현재 구조를 유지한다. 데이터 홈은 ~/ComicTranslator다.

## 데이터

- projects, cache/input, cache/cv, cache/analysis, glossaries, exports, inbox, samples, legacy, backups 구조를 유지한다.
- scripts/prepare_workspace.py로 데이터 홈 안에 README.md와 기본 폴더를 준비했다. 기존 데이터와 안내를 덮어쓰지 않는다.
- 약 196MB big-lama.pt를 ~/.cache/torch에서 데이터 홈 cache/models/torch/hub/checkpoints로 복사했다.
- SHA-256 동일성을 확인했고 기존 사본과 이전 백업은 삭제하지 않았다.
- configure_model_cache에서 TORCH_HOME의 기본 위치를 데이터 홈으로 정하며, 명시한 환경변수는 보존한다.
- 모델 파일이 있으면 LAMA_MODEL로 사용한다. 동일 파일로 CPU 추론 64×64 출력을 확인했다. 다운로드·유료 호출 0.

## 패키지

직접 import와 설치 메타데이터의 재귀 의존성을 대조했다. 새 기능·API 모델·번역 정책은 바꾸지 않았다.

- 기본 requirements.txt: FastAPI, MCP, OpenAI, requests, CV·렌더, LaMa. 동작 검증한 버전 고정.
- requirements-dev.txt: 기본 + pytest, httpx.
- batch/requirements.txt: 기본 + google-genai. 선택 배치 도구 전용.
- requirements-lock-macos-arm64-py311.txt: 정리한 실제 설치 환경의 전체 freeze.
- 배치 업로드는 구형 google-generativeai에서 google-genai client.files.upload로 바꿨다. 모의 호출로 MIME와 파일 전달을 확인했다. 실제 배치 전송은 하지 않았다.
- REST Cloud Vision 코드에서 사용하지 않는 google-cloud-vision SDK를 제거했다.
- 폐기된 Gradio와 전용 패키지, pandas, Hugging Face 도구 등 42개를 .venv에서 제거했다. 전체 설치 110 → 68개.
- torch·torchvision·simple-lama-inpainting은 실제 사용하는 필수 패키지이므로 유지한다.
- 현재 Cloud Vision은 API 키 REST 방식이라 google-credentials.json은 현재 필수 파일이 아니다. 기존 파일은 보존한다.

정리 전 전체 설치 목록·유지/제거 계획은 데이터 홈 backups/dependencies-before-cleanup-20261021.json에 보존했다.
독립 설치 목록의 범위와 LaMa wrapper의 Pillow/NumPy 제약은 docs/DEPENDENCIES.md에 기록했다.

## 검증

- pip check: 충돌 없음.
- 설치 dry-run(--no-index): 기본·개발·배치 목록 모두 현재 환경에서 충족.
- 기능 테스트 518개 및 13개 subtest 통과. 문서 동기화 검사는 커밋 뒤 다시 확인한다.
- LaMa 실제 모델 로드 및 CPU 추론 통과. 출력 크기와 유한 값만 확인했으며 시각적 복원 품질 판정은 하지 않았다.
- 원본 프로젝트, 출력 이미지, 이전 백업을 삭제하지 않았다.
