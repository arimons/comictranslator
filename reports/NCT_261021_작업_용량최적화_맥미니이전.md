# 데이터 용량 최적화와 맥 미니 이전

2026-10-21. 데이터 홈 `~/ComicTranslator`를 정리하고 기존 SSH 키로 맥 미니에 복사했다. 코드 위치는 `~/Developer/NEW_COMIC_TRANSLATOR`, 데이터 위치는 `~/ComicTranslator`로 유지한다.

## 정리 기준과 결과

- 용량: du 기준 약 32G → 12G. 삭제한 파일 68,531개, 논리 크기 21,215,393,116바이트. APFS 복제본이 포함되어 있으므로 이 숫자는 실제 디스크 회수량과 다를 수 있다.
- 이전 백업 중 현재 보관 사본과 크기·SHA-256이 같은 파일만 제거했다. 보존 사본도 삭제 직전에 다시 검증했다.
- 프로젝트가 참조하지 않는 검증·벤치마크 이미지와 그 백업을 제거했다. 측정값·CV/OCR/번역 JSON과 검증 스크립트는 남겼다.
- 활성 프로젝트의 최종 결과 439장, CV 캐시 726개, 분석 캐시 12,311개는 SHA-256 변경 없음. 원본 1,913개도 크기·수정 시각 변경 없음. 활성 입력 1,134장 모두 존재한다.
- 예전 프로젝트 13개는 실제 수동 편집 기록이 있어 `legacy/projects_test`에 보존했다. 기존 완성 번역본도 `legacy/output`에 보존했다.
- `cache/input`은 기존 프로젝트·보관 프로젝트와 대체 입력 참조가 있어 유지했다. 향후 정리는 활성·보관 참조와 대체 경로를 함께 조사해야 한다.
- 삭제 파일별 경로·해시 기록은 데이터 홈 `maintenance/cleanup-20261021.json`, `maintenance/bench-cleanup-20261021.json`에 보관한다.

## 전송 방식

대상 호스트 주소는 공개 저장소에 기록하지 않고 로컬 작업 설정에서 관리한다.

- 기존 SSH 키로 접속했다. 키 내용을 출력하거나 새로 만들지 않았다.
- 맥 미니의 기존 원본 1,747개는 Finder `.DS_Store` 외에 내용이 같았다. `samples/test_image1`은 기존 원본 폴더를 가리켜 중복 복사하지 않는다.
- 기존 캐시·결과물을 새 데이터 홈의 **누락 파일에만** APFS 복제로 재사용했다. 복제본은 쓰기가 독립적이며 원래 파일을 이동·덮어쓰지 않는다.
- 최신 변경은 rsync 체크섬 비교로 전송한다. 대상 삭제 옵션을 사용하지 않고, 갱신 전 원격 파일은 `backups/remote-before-transfer-20261021`에 보존한다.
- 맥북의 `backups`와 `.DS_Store`는 전송에서 제외한다. 프로젝트·캐시·분할 이미지·과거 결과·용어집·연결 설정·정리 기록은 복사한다.
- `.venv`는 복사하지 않는다. 맥 미니의 기존 환경에서 앱 import는 통과했다. Python/일부 패키지 버전은 맥북과 달라 동일한 가상환경을 복제한 것은 아니다.

서버를 옮겨 운영할 때는 두 기기에서 같은 프로젝트를 동시에 편집하지 않는다. 맥북은 이전 확인용으로 유지하고 실제 작업 서버를 하나로 정한다.

## 실행

```sh
cd ~/Developer/NEW_COMIC_TRANSLATOR
.venv/bin/python app.py --no-browser --port 7873
```

기본 주소는 서버 자신의 `127.0.0.1`에 바인딩된다. 다른 컴퓨터에서 접근할 때는 SSH 포트 포워딩을 사용할 수 있다.

```sh
ssh -N -L 17873:127.0.0.1:7873 USER@MAC_MINI_HOST
# 브라우저: http://127.0.0.1:17873
```

원본이 다른 위치로 이동했다면 편집기 ‘원본 연결’에서 해당 서버의 폴더 경로를 다시 지정한다. 자세한 저장 계약은 [원본 입력 관리](../docs/INPUT_SOURCES.md)를 참고한다.

## 원격 검증

- 활성 프로젝트 15개, 입력 1,134장. 일반 969장 직접 연결, 분할·크롭 165장 보관. 입력 누락 없음.
- 원격 CV 캐시 726개·분석 캐시 12,311개·최종 이미지 439개 SHA-256 대조: 변경 없음.
- 원본 연결 한 프로젝트는 상위 폴더 아래 심볼릭 링크가 보안상 경계 밖으로 해석되어 실제 원본 루트에 다시 연결했다. 맥북과 맥 미니의 논리 원본 ID를 맞추고 각 호스트 경로를 별도 등록했다. 이전 manifest는 보존했다.
- rsync 체크섬 dry-run에서 일반 파일 내용 차이 없음. 호스트별 연결 설정과 검증 기록은 기기별로 추가될 수 있다.
- Git 추적 코드도 체크섬 비교 후 누락된 검증 스크립트를 보충했다. `.git`과 `.venv`는 복사하지 않았다.
- 맥 미니의 임시 HTTP 서버로 health·홈 HTML·최근 프로젝트·원본 연결 API 확인 후 종료했다. 최근 목록은 기존 그룹화/최대 10개 사양이며 전체 프로젝트 수와 다르다.
- 기존 LaMa 모델 캐시로 64×64 CPU 추론 성공. 모델 다운로드 0회, 유료 API 0회.
- 상시 서버/자동 시작 서비스는 새로 등록하지 않았다. 맥북의 기존 로컬 편집기는 복사 완료 후 다시 실행한다.
