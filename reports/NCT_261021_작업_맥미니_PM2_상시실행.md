# 맥 미니 PM2 상시 실행

2026-10-21. 기존 PM2 운영 방식에 맞춰 `comictranslator`를 등록했다.

- 설정: `deploy/pm2/ecosystem.config.cjs`. Python 가상환경으로 앱을 실행하고 localhost 7873만 수신한다.
- 자동 재시작과 `pm2 save`를 설정했다. 기존 저장 목록은 비공개 백업 후 갱신했다.
- 기존 PM2 LaunchAgent가 로드되지 않아 원본을 백업하고 `RunAtLoad` 일회성 복구 작업으로 정리해 로그인 도메인에 등록했다. 현재 맥의 자동 로그인·FileVault Off 설정에 따라 재부팅 후 로그인 시 저장된 PM2 앱을 복구한다.
- Tailscale Serve의 기존 HTTPS 443 프록시는 유지하고, tailnet 전용 HTTPS 8443 프록시를 추가했다. 기존 설정은 비공개 백업했다. 호스트 실주소는 공개 문서에 기록하지 않는다.
- 맥북에서 HTTPS health 응답 확인. 새 앱만 종료한 뒤 PID 변경과 health 복구로 PM2 자동 재시작을 검증했다. 다른 PM2 프로세스는 PID·상태가 그대로였다.
- 실제 재부팅이나 전체 PM2 데몬 재시작은 하지 않았다. launchd 등록·저장 목록·앱 자동 재시작을 확인했다.
- 추가 패키지 설치나 유료 API 호출은 없었다. SSH로 대상 `.venv`의 패키지를 관리할 수 있다.

운영 명령과 재설정 방법은 [PM2 운영](../deploy/pm2/README.md)을 참고한다.
